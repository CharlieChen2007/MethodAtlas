# MethodAtlas 作品 DEMO 视频脚本（3 分钟）

> 录制前请先看「录制准备」；分镜表里 **画面 / 操作 / 旁白** 三列可以直接照着念。
> 旁白按 **正常语速** 写（约 4.5 字/秒），每段时间都已配平，总长约 2′55″。

---

## 录制准备（录之前 10 分钟做掉）

| # | 事项 | 说明 |
|---|---|---|
| 1 | **把 dev server 换成生产模式** | `npm run build` → `npm run start`。生产模式首屏快、无编译水印，录出来更专业 |
| 2 | 关闭无关标签页与通知 | 特别是微信/QQ；浏览器用**无痕窗口**，避免插件图标入镜 |
| 3 | 浏览器窗口固定 1440×950 左右 | 保证"一屏不滚动"这个亮点在画面里成立 |
| 4 | 缩放设为 100% | 别用 110%/125%，否则看板文字会糊 |
| 5 | **先点一次开场页的「开始探索」** | 否则视频开头是欢迎页而不是工作台（若想演示开场页，见第 1 段备选） |
| 6 | 确认**没有「离线模式」徽标** | 有徽标说明降级到演示数据了 —— 录出来会被评委看出不是真模型 |
| 7 | 预跑一遍操作路径 | 尤其「抽取方法结构」等长任务**别在录制时现场等**，见第 3 段说明 |

## 录制小贴士

1. **旁白与画面错开录**：先按分镜表把操作录成无声视频，再单独配音。
   边操作边念很容易卡壳，重录成本高。
2. **鼠标动慢一点**：评委看的是"信息密度"，快速乱甩会显得慌。
   每段操作之间留 1 秒静止，给人看清的时间。
3. **不要现场等长任务**：抽 DNA / 演化 / 债务 / 击穿都要真实调模型（几十秒到几分钟）。
   库里**已经预置了完整结果**，直接展示即可 —— 这也是为什么演示库要随包交付。
4. **一定要露出看板**：它是"数据看板化"改造的成果，也是和普通 demo 的差异点。
5. **检查「离线模式」徽标**：录之前确认没有它，否则等于在说"我这是假数据"。
6. **导出参数**：1080p / 30fps / H.264，码率 6–8 Mbps 足够；3 分钟约 40–60 MB。
7. **录完自检**：按「六、部署后自查清单」逐条对一遍，确认视频里每条都露过面。

## 可直接用的旁白全文（连起来约 2′55″）

> MethodAtlas —— 一个把论文变成可操作研究方法图谱的科研工具。
> 它不是论文摘要器：它抽取方法结构、追踪技术演进、找出领域里长期没人解决的问题，再帮你组合出新研究方向。
>
> 每篇论文被拆成方法模块，并按研究流程的 7 个阶段定位：问题、输入、预处理、核心方法、训练、推理、评估。
> 点任意模块，右侧给出它的作用、在方法中的角色，以及证据来源。
>
> 这是它和"AI 编综述"最大的区别：每个结论都挂证据。
> 证据分三档 —— 原文事实、模型归纳、模型推断；强度不足的会被标成"证据有限"，不允许当作已证实的结论。
>
> 演化视图把 8 篇 Wi-Fi 指纹数据增强的论文按年份排成一条链：GPR、GAN、扩散模型、VAE、元学习。
> 点开一行，右侧告诉你这篇论文针对哪个问题、用了什么方法、结果如何。
>
> 把论文里的"局限"升级成领域欠下的债：不是单篇的不足，而是多篇反复撞上、至今没解决的问题。
> 这一条被 5 篇论文提及 —— 这就是值得做的地方。
>
> 它不只整理文献，还会提出方向：把不同论文的方法模块与债务组合，生成候选方案。
> 然后先自我否定 —— 这是"击穿测试"：从新颖性、模块冲突、数据可行性、算力四个维度找茬。
> 其中一个方案被判"不可行"，报告直接说明为什么、并且给出怎么改。
>
> 底部是数据看板：4 张统计卡加 2 张图表，一屏内看完，不需要滚动。
> 阶段分布能立刻看出这条技术路线重心在哪、哪里薄弱。
> 看板可以折叠 —— 需要专注看结构时就收起来。
>
> 几个工程上的坚持：
> 一屏不滚动，全部信息在首屏完成；
> 界面不出现任何模型名称 —— 换模型不改一行代码、也不影响界面；
> 不绑定具体大模型，任何 OpenAI 兼容服务都能接；
> 所有 AI 结论都带证据强度，宁可标"证据不足"也不硬给结论。
>
> MethodAtlas —— 让论文里的方法，变成你能动手改的结构。
