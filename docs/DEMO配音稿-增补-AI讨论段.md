## ⚠️ 三条必须知道的事实（都是从录像里核出来的）

### 1. 录像里 AI 讨论**只有"问题 + 正在思考"，没有回答**

时间点实测：

| 源时间 | 画面 |
|---|---|
| 04:45 | 对话输入框，**发送**按钮为可点状态 |
| 04:50 | **AI 讨论** 面板：「正在讨论：用未标注众包RSSI… · 已带击穿结果」+ 左侧「正在思考…」 |
| 04:55 | 对话区出现长文本（浅色，像是回答在流式输出） |
| 05:00 | 仍在输出，右下角出现「与MethodAtlas共同探索」浮标 |
| 05:10 | 击穿视图，浮标可见 |
| 05:15 | **切到演化视图 —— 画面空白** |

**结论**：录像**没有**录到"问风险 / 问改进方向"的完整问答。
所以旁白里"比如问它…"用的是**举例语气**（"可以问它…"），
而不是断言"我们问了、它答了" —— 否则配音与画面不符。

**如果你想让这段更有说服力**，最省事的做法是：**补录 20–30 秒**——
现在就打开 http://localhost:3000，进击穿测试视图，点「与MethodAtlas共同探索」，
真的问一句「这个方案最大的风险是什么？」，等它答完，把这段屏幕录下来插入。
这样就能用完整版旁白（109 字）并真实展示问答。

### 2. 05:15–05:25 是**空态与加载**，不该留在成片里

实测：05:15 = 演化视图空白；05:20 = 加载中空白；05:25 = DNA 视图（73 个模块 / 86% 证据覆盖）。

原 v3 方案把 `05:14→05:27` 当成"击穿判定 + 看板分布"，**是错的** ——
那 13 秒里有两段空白。**这段应该删掉**，"判定 + 看板"用 `05:10 → 05:14` 那 4 秒就够。

> 这也是我第三次在该录像上写错时间码。教训：**每个时间点都要打开那一帧看一眼**，
> 不能凭"上一个 5 秒帧是什么"推断中间的 5 秒。

### 3. 「与MethodAtlas共同探索」**只在击穿测试视图出现**

这一点我一开始写错了（以为它是全局浮标）。查源码确认：

```tsx
// LabShell.tsx L2345
{view === 'crashtest' && (
  <button data-explore-fab ... onClick={() => setChatOpen(o => !o)}>
```

它的出现条件就是 `view === 'crashtest'`。源码注释里还写了原因：
早期它在 DNA 视图也出现，但那里**没有 AI 讨论面板**（`CrashChatPanel` 只在 crashtest 渲染），
点了只会把 `chatOpen` 置位、用户看不到任何反馈，是个"点了没反应"的死按钮 ——
所以改成了只在击穿测试视图出现。

**对剪辑的意义**：想强调这个入口，**只能在击穿测试那段（04:45–05:14）取镜头**，
不能从 DNA 视图取。
