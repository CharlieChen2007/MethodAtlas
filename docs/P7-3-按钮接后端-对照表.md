## 数据流：为什么"点一下就有反应"

```
用户点击 (Client Component)
      │
      ▼
Server Action（'use server'，src/lib/actions/*.ts 或 app/**/actions.ts）
      │   鉴权 / 参数校验 / 调 pipeline
      ▼
Pipeline（src/lib/*.ts，纯业务逻辑，不碰 UI）
      │   调 LLM（LLM_PROVIDER=mock 时走 src/lib/llm-mock.ts）/ 调解析服务 / 算证据
      ▼
Prisma 写库（prisma/dev.db）
      │
      ▼
router.refresh()  ← LabShell 里统一调用
      │   重新执行 lab/page.tsx 的 RSC 聚合查询
      ▼
画布按新数据重排（buildViewLayout）→ 用户看到真实变化
```

**关键点：全程不跳页。** URL 用 `history.replaceState` 同步（`?view=surgery` 等），
所以刷新/分享链接仍能回到同一视图，但点击本身不触发整页导航。
